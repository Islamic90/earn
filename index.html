Chat Completions

Send messages and get AI responses using the Chat API.

POST https://api.spacez.ai/v1/chat/completions
POST /api/v1/chat/completions

Create a chat completion with the given messages.

Request Parameters

Parameter Type Required Description
model string Yes AI model to use
messages array Yes Message history array
temperature number No 0.0 - 2.0 (default: 0.7)
max_tokens integer No Maximum response tokens

Example Request

curl -X POST https://api.spacez.ai/v1/chat/completions \ -H "Authorization: Bearer sk-proj-YOUR-KEY" \ -H "Content-Type: application/json" \ -d '{ "model": "spacez-v1", "messages": [{"role": "user", "content": "Hello!"}], "temperature": 0.7, "max_tokens": 1024 }'

Response Structure

{ "id": "chatcmpl-8H9k2L3m", "object": "chat.completion", "created": 1695123456, "model": "spacez-v1", "choices": [{ "index": 0, "message": { "role": "assistant", "content": "Hello! How can I help you?" }, "finish_reason": "stop" }], "usage": { "prompt_tokens": 10, "completion_tokens": 15, "total_tokens": 25 } }
